# Prompt Wars — mockup fidelity audit

Date: 15 September 2026. Scope: compare the current client with the approved Arena, battle-workspace and Cosmetic Shop mockups, then identify shared components that carry those gaps into other screens. This audit creates documentation and evidence only.

## Conclusion

The migration established the palette, display font, reusable controls and much of the required behavior. It has not achieved visual fidelity to the approved compositions. The largest remaining differences are the fighter card/stat assembly, duel header, theme illustration, bespoke icons, lock-in treatment and Shop hierarchy. Passing functional tests did not establish visual acceptance.

The user's listed concerns are confirmed. The theme image is present in code, but an 82% opaque surface obscures it. Shop categories exist, but they are individual bordered buttons rather than the mockup's tab rail. The four-stat layout visibly becomes three cells plus Focus on a second row at ordinary phone size.

## Differences to preserve or treat explicitly

- **Pending-round placement:** the implementation plan deliberately moved action-needed content before the hero. Keep that priority and apply the illustrated strip treatment there.
- **Large text:** four stats on one row are the normal layout; a balanced 2×2 grid is an accessibility adaptation. Five category tabs can scroll horizontally. Essential labels must not shrink, truncate or be forced into unsafe one-line layouts.
- **Different equipment:** a player wearing Neon Circuit should not silently acquire Astral Codex to resemble Mira. Equipped frames replace the default art border. Never add another ornamental frame or stretch circular frame artwork to force a rectangular mockup silhouette.
- **Theme artwork:** the existing six bundled moods are selected deterministically from free text. They are decorative atmosphere, not literal scene illustrations for every possible prompt. Visible atmosphere can be fixed entirely on the client; literal semantic theme illustrations would require a separate catalog/data decision.
- **Catalog contents/order:** the mockup shows four examples; the current catalog also includes Classic, Veteran, Gold and Plus. Keep all products and server prices. A featured four-frame first row is an optional merchandising decision, not a missing entitlement or a reason to remove older products.
- **Additional features:** quests, rival information, equipment slots, authoring modes, free/paid ideas, safety actions, failure states and long content remain. The static mockup's omissions do not authorize their removal.
- **Static image proportions:** do not compress a native screen to fit every item visible in an illustrative raster. Match hierarchy, grouping, silhouettes and materials at a real viewport; let content scroll.
- **No whole-screen images:** new icons and branding may be assets. Text, prices, HP, menus, prompts, deadlines and interaction states remain native dynamic UI.
